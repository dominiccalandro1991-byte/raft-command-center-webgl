# Raft Command Center

Isolated Vite + React + TypeScript + Three.js (React Three Fiber) operations console for cottonwood-log raft deployment.

## Stack

- Vite + React 19 + TypeScript
- Three.js via `@react-three/fiber` + `@react-three/drei`
- Tailwind CSS v4
- `lucide-react`

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Views

1. Materials — field specifications for pontoons, decking, bindings, tools
2. Assembly — three-phase construction protocol
3. 3D Render — orbitable WebGL hull
4. Simulation — Mississippi River vs Southern Illinois lakes hydrodynamics
